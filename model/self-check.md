# 爆火要素自检清单（可打分）

> 配套 本库的实测数据。
> **用法**：给一个 VTuber 企划（或已出道的主播）逐条打分，**0 / 1 / 2** 三档。
> 满分 48 分。**不要看总分，看有没有 0 分项** —— 模型是乘法，0 分项会直接把总量清零。
>
> 打分的意义不是「预测会不会火」，而是**找出那个把一切归零的短板**。

---

## 使用说明

- **0 分** = 没有 / 完全没做
- **1 分** = 有，但弱、不稳定、或没被系统化
- **2 分** = 明确做了，且可重复、可持续

**先看 0 分**：任何一条 0 分都必须优先处理，因为它会让其他所有投入打折。
**再看总分**：
- **0-15 分**：还没进场（入场层都不完整）
- **16-27 分**：能活，但很难出圈
- **28-38 分**：有出圈潜力，缺的是风或时间
- **39-48 分**：头部结构已经具备，剩下的是运气与执行耐久度

## 最重要的一句话

**不要用这张表去预测谁会火，用它去找出那个会把你归零的短板。**
本表的所有条目都来自对幸存者的逆向拆解 —— 它能告诉你**别人做对了什么**，
但**不能告诉你这些做对了的人里有多少没火**。
