# Virtual Heroine Atlas

**132 personnages virtuels féminins : pourquoi ils attirent, comment leur image est construite.**

Un atlas de recherche lisible dans Obsidian, interrogeable en CLI et utilisable avec DeepSeek Harness.

[中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · **Français**

## Contenu

- 132 streameuses / personnages virtuels féminins
- une fiche par personnage
- pourquoi ils attirent : contenu et stratégie
- comment ils sont conçus : couleurs, structure du costume, expressions, langage, position émotionnelle
- prompts en couches pour modèles d’image

## Usage

```bash
python3 query.py --help
```

Ouvrez les fiches et images dans Obsidian ; interrogez en CLI ou via DSH.
