# 七诗无明 / Nanashi Mumei

> **一句话定位**：把「文明」这种抽象概念拟人成一只呆萌猫头鹰，再用同一套设定把「看得见的可爱」和「看得见的黑暗」焊在一起——她是 hololive EN 里反差结构最工整的一例。

- **视觉**：猫头鹰系少女。判别特征是**大而圆的眼睛、羽毛状的发饰／耳羽、以及偏米白的低饱和配色**——整套设计把「可爱」放在第一眼，「古老观察者」的信息要靠设定文本才读得到。这就是她反差结构的前半段在视觉上的落地：外形先交付无害，设定再补上重量。

## 六、可复用要素

1. **F04 反差结构（本卡重点）** — 她的反差不是「人设 vs 本人」这种不可核实的东西，而是**两段都在官方设定文本里**：一段是「文明的守护者／见证无数事件的长途旅人」，另一段是「一只享受每一天的可爱女孩」。两段之间的落差就是她的内容引擎。可迁移动作：写设定时把**抽象量级**（文明、时间、自然这一类）和**具体萌点**（体型、口癖、笨拙）各写一条，并且**两条都写进官方设定**——只在直播里演出来的反差，观众不会替你做设定考据。
2. **F02 声音记忆点** — 招呼语把猫头鹰叫声（Hoo）嵌进问候，粉丝名（Hoomans）又复用同一个音，形成**同一个音节在角色名、问候语、粉丝名三处重复**的结构。可迁移动作：选一个音节，让它在招呼语、粉丝名、频道口头禅里各出现一次；重复三次以上，它才成为资产。
3. **F07 二创友好的分发契约** — 官方把配信、画作、meme 三类二创分别给了 tag，等于告诉粉丝「你可以用哪三种方式生产」。可迁移动作：不要只发一个「二创欢迎」 tag，按内容形态分列（剪辑／画作／梗图），把模糊的许可变成可执行的清单。
4. **F09 长期在场的复利（反向样本）** — 她的曲线提供了一个**负面参照**：毕业后频道仍在、数据不衰减，但角色本身不再产生新内容，商业化随之停止。可迁移动作：把「档案资产」和「在场资产」分开记账——档案能维持订阅数字，但只有持续在场才能把数字换成收入。
5. **不可迁移的部分** — （a）2021 年 Hololive English 第二代出道名额与「概念拟人」这个官方企划框架，是公司分配的一次性位置；（b）她的反差结构成立的前提是 hololive 级别的设定文本与美术资源，个人势很难为「文明」这种量级写出可信的设定包装；（c）毕业是**健康原因导致的被动收束**，不是一种可以借鉴的运营策略，把它当作路径参考是对当事人的二次消费。

## 七、人物形象分析

- **人物形象**：官方全身立绘，1000×1556 竖构图〔测量：本卡图片尺寸〕；约 6 头身，双腿并拢直立，一只手抬到眉侧——既像敬礼又像遮光远望。拟人化母题是**猫头鹰 + 旅人**：头顶两枚带斑纹的羽毛状耳羽，圆瞳大眼、短圆口鼻；「旅人」落在腰侧那盏**点亮的黄铜提灯**上。设计上最值得抄的一点是：她把「观察文明」这个抽象设定转译成了两个具体道具——**手搭凉棚的姿势**（观察）与**提灯**（照亮），于是设定不需要文字也能在剪影里读到。
- **性格分析**：本卡第一、三段记的官方设定是「文明的守护者（The Guardian of Civilization）」＋一个享受日常的可爱女孩，两段都写在官方文本里。看图能独立读出的只有**无害、松弛、略笨拙**这一半——大圆眼、张开的圆嘴、抬手挠头式的姿势都在交付「不要警戒我」。所以这张立绘本身就是她**反差结构的前半段**：外形先把重量藏起来。设定文本里那个「见证过无数事件的古老观察者」在图上找不到对应的视觉证据（如岁月感、厚重感），二者是刻意错开的。她的具体身高数值见官方 DATA（本卡第二段），不在本段重复。
- **服装分析**：白灯笼袖衬衫 + 黑领结打底；肩上盖一件卡其色披肩，边缘是锯齿／流苏剪裁；外面套深棕束身胸衣，压印金色太阳与星形徽记；下身赭红打褶短裙，正面一枚金色纹章；黑色腰带（金扣 + 一条蓝绳）；腰侧挂**黄铜提灯**（全身唯一的发光件）、一只小皮包与一截剑柄；手戴黑色手套，腿是黑色过膝袜（一条腿带吊袜带），脚踩黑靴、靴口翻出暗红色褶边。披风内衬是**暗青色**，在画面上摊开成最大的那块青。材质读起来是哑光呢料 + 皮革，金属件只出现在徽记、扣具与提灯上。功能性上，她把所有道具压在腰以下、腰以上只留「耳羽 + 领结」两个识别点，所以缩略图裁到胸口也不会失去身份。
- **表情分析**：默认态＝金色大圆眼 + 微张的小圆嘴，情绪落在「呆」与「专注」之间；眉不压、眼角不上挑，没有任何攻击性读数。立绘只给了这一种表情，笑／惊／怒／窘的完整表情谱在静帧上无法穷举：未核实。
- **常用语言分析**：图上无文字、无台词，**这张图不能作为语言证据**。可复读的单元见本卡第三段记录的官方招呼语 `Oh hi! Hoo's this? Nanashi Mumei!`（把猫头鹰叫声「Hoo」嵌进问候）。她的自称、语尾、其余口癖的逐项清单：未核实。
- **人物情绪分析**：图上读到的是**低张力 + 好奇**：抬手遮光的动作给了「刚要开口」的瞬时感，重心稳定、肩膀不上耸，读不出紧张或亢奋。情绪光谱与触发点在静帧上不可测：未核实。可核实的是她的情绪曾长期被健康问题限制（见第三段），那是文本事实，不是这张立绘的证据。
