## 六、可复用要素

1. **F02 声音记忆点** — 官方直接把「◯◯ぺこ」列为语尾 meme，意味着她的声音本身是可检索的品牌标记。可迁移动作：为角色设计一个**在所有句子里都会出现**的语尾或口癖，而不是只设计一句招牌台词。
2. **F03 可剪辑的最小内容单元** — 高难度游戏挑战自带「失败—崩溃—重来」的三段结构，天然适配切片。可迁移动作：把企划设计成有明确成败判定的挑战，而不是无结构闲聊。
3. **F05 失控感与不可预测性** — 她的娱乐性来自高张力情绪与即时反应（官方 meme 里的「きtらあああああ」就是这种失控瞬间的文字化）。可迁移动作：保留不剪辑的即时反应作为内容核，而不是全部做成脚本化的「节目」。
4. **F09 长期在场的复利** — 2749 支投稿的供给量意味着她可以持续从旧素材里长出新商品（酒类联名直接回采 2019 年直播片段）。可迁移动作：把每次联名都设计成「回采旧直播梗」的机制。
5. **F07 二创友好的分发契约** — 配信 tag 与粉丝绘 tag 分开，配合小説化把角色关系开放给二次创作。可迁移动作：为不同创作类型（绘、剪辑、文本）分别给出明确 tag 与授权口径。同期的 [[宝钟玛琳]]、[[白银诺艾尔]] 走的是同一份箱内合约，可横向对照三张卡的 tag 结构差异。
6. **不可迁移的部分** — 2019 年 hololive 三期生的出道红利、以及「长时间游戏耐久」这一形态可用的平台环境（当时的算法与观众容忍度）已变；児童文庫级别的出版机会来自她在**日本小学生女童**群体中的独占位置（公开报道引述小学馆调查称其为该群体最喜欢的 VTuber 第 1 名），这属于不可复制的市场时机。

## 七、人物形象分析

- **人物形象**：第一眼是**「蓝白配色的兔子」**——极浅的蓝白渐变长发编成两条粗三股辫垂在身体两侧，发辫上挂着**胡萝卜造型的发饰**；红瞳（偏洋红），头顶一对长兔耳（耳内为粉色）。主体是一件白色无肩带洋装：胸前是蓝色十字形系带，腰侧与裙面印着淡蓝色的兔爪印，裙边与肩部围着一圈**蓬松的白色毛绒**。颈间趴着一只白色小兔「どんちゃん」（官方标注「生きてます」＝还活着），腰侧另插一根胡萝卜。姿态是一手抬至脸侧、一手向外张开、单腿抬起的**跳跃感站姿**。母题上她是「一根会跳的胡萝卜」：兔耳是种族，胡萝卜是执念，两者都在立绘上被做成了可摘取的实体道具。
- **性格分析**：官方设定是「寂しがり屋なうさ耳の女の子」，爱吃胡萝卜到随身携带，梦想栏写着「全世界野うさぎ計画！！！！！！！！！！」。立绘与这段文字的关系是**完全同向的夸张**：她不是「安静的可爱」，而是「一眼就能看出在闹」的可爱——发辫、道具（兔、胡萝卜）、跳跃的站姿、以及那张张着嘴的笑脸，四件事同时在喊「看这里」。这与她内容层的形态是一致的：长时间游戏实况 + 高难度挑战 + 观众参与企划，需要的正是一个**能量不衰减的封面形象**。她的「寂しがり屋」这一条则提供反差面：表面吵闹、设定上怕孤单，这让粉丝名「野うさぎ同盟」有了叙事上的必要性——观众是她的同伴，而不是观众。
- **服装分析**：结构上是**白底蓝饰的单件式洋装**，附件全部做成可摘的实体。上身为无肩带洋装，胸口蓝色系带在中央打结，肩部与裙摆各围一圈白色蓬松毛绒（材质暗示是兔毛）；裙面印淡蓝色兔爪印，左侧腰际系一枚蓝色蝴蝶结，右侧插一根胡萝卜。四肢：白色毛绒手套（腕口有蓝结）＋黑色指套式的「爪子」手，腿为黑色过膝紧身袜（与白色洋装形成强对比），脚穿白色毛绒短靴（靴面有蓝结与蓝色厚底）。头部：长兔耳（内耳粉）、两条麻花辫、胡萝卜发饰。功能上：白色毛绒与黑色过膝袜的明度对撞是她最强的缩略图信号（黑白两块立即成图），兔耳与麻花辫提供横向与纵向两个方向的轮廓延伸，使她即使被裁成方图也仍然认得出；胡萝卜与「どんちゃん」是可以单独拿出来做周边与二创的实体道具。
- **表情分析**：立绘是**全开的高能量笑脸**：眉毛上抬、眼睛睁大且亮、嘴巴张开露出上排牙齿，头部微微上扬。这是「正在喊」的表情，不是「正在微笑」的表情——它承接的是她内容里最常见的那一类瞬间（惊呼、起哄、得意、急着说话）。可推的常见表情谱系：高笑／起哄（立绘态）→ 得意脸（企划成功时）→ 瞬间惊恐或抗议（失败时）→ 装可怜／撒娇（寂しがり屋那一面）；后三种在本图里**看不到**，属于按官方设定与语尾系统推导的预期。
- **常用语言分析**：开场台词「こんぺこ！こんぺこ！こんぺこー！兎田ぺこらぺこ～！どうも〜どうも〜」——把招呼语做成三连重复，自带节拍，是本批里最容易被弹幕接龙的一句。核心语言资产是**语尾系统**：官方把「◯◯ぺこ」单列为 meme，即任何词都能接上「ぺこ」；另一条定番是「きtらあああああ」。这套语尾的复读性极高，因为它不依赖具体内容——观众可以把它接到任何句子上，等于给二创提供了一条免学成本的语言接口。自称「ぺこら」；粉丝名「野うさぎ同盟」。
- **人物情绪分析**：情绪光谱是**极高能量、快速起落、以「吵」为主表达**。典型触发点由官方 meme 列表给定：胡萝卜（执念）、「ぺこらんど」（她设定的出生国）、以及「寂しがり屋」这条内里。她的情绪设计对内容的用处很明确：长时间实况需要一个能持续输出反应的主播，而她的形象与语尾都预设了「反应会很大」——观众看的是她**对事件的态度**，事件本身只是引子。另一面，怕孤单这一条把高能量从「表演」变成了「需求」，观众因此不是围观者而是「野うさぎ同盟」的成员。安静／低落状态的样本：未核实。
- **配色分析**：

 - ⚠️ 测量陷阱：参考图是**透明底 PNG**，工具把透明区读成近白，因此占比最大的 `#F8F7F9`（56%）**首先是透明背景，其次才是她本来就很白的洋装**——两者在这张主色表上分不开，`#F8F7F9` 不能直接当作「角色主色」。而 `#1A1617`（7%）这一档才是**真正的角色深色**：黑色过膝袜与黑色爪指。也就是说这张图里「高明调 + 高对比」的结论是对的，但成因里混了一项测量伪影，必须回到图上确认哪些白是衣服、哪些白是背景。扣掉背景后，角色侧可用色为：淡蓝 `#9DB1DA`（发与裙面印花）、冷灰 `#91929B`（布面阴影与毛绒暗部）、`#71768E`（发的中间调）、黑 `#1A1617`（过膝袜与爪指）、以及图上可见但未进入主色表的粉色内耳与橙绿胡萝卜。

**冲突消解记录**：自动丢掉了 **2** 个打架的负向词——`muted colour`（出自 `superflat` 风格层）与 `muddy colour`（出自 `anime-cel` 光照层）。原因是这两层在正向侧都要求 `colour`（超扁平的高饱和平涂、赛璐璐的平涂色块），而它们自己的负向表又都禁掉「不鲜明／浑的颜色」；**不丢就会与本层正向的用色要求直接自相矛盾**，把两层都要的平涂彩色一并排除。原因一句话：丢掉的是与自身正向要求冲突的负向词，不丢就会连带排除正向需要的元素。

**可迁移 / 不可迁移**：**可迁移**的是设计动作——用「白 + 单色 + 黑色压脚」的三段式明度结构保证缩略图可读、把设定里的执念物件做成实体配饰（胡萝卜、肩上的小动物）、用一组可摘道具为周边与二创预留接口、以及把口癖做成语尾系统（任何词都能接「ぺこ」）而不是固定台词。**不可迁移**的是绑死在她身上的部分：兔耳 + 胡萝卜 + 「どんちゃん」这套已被「野うさぎ同盟」认领的组合、「こんぺこ」开场与「◯◯ぺこ」语尾、以及 2019 年 hololive 三期生出道红利与她在日本小学生女童群体中的独占位置。
