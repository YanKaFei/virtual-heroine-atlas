- **角色设定**：官方档案写「クレッシェンドな日々を過ごす音楽家の卵。どんな時も彼女の側に音楽はある。喜怒哀楽が表に出やすく、好きなことのためならどこまでも頑張れるが、苦手なことにはつい眉をひそめてしまう幼さがまだ残っている。けれど、美味しいご褒美があれば話は別」。开场固定台词「ドレミファソラシド～！hololive ReGLOSSの音楽家の卵！音乃瀬～奏で～～～す！」，生日 4 月 20 日，身高 153cm，插画师 gomzi，粉丝名「音の勢」，配信 tag「#生音乃瀬」，艺术 tag「`#Artnose`」，推しマーク 🎹✨。初配信 2023-09-09 20:30（ReGLOSS 五人中的第二棒）。

- **视觉**：官方给出的符号是推しマーク 🎹✨ 加上「音楽家の卵」这一身份，配信 tag「#生音乃瀬」与艺术 tag「`#Artnose`」把「生（现场）」与「Art」两个词分别钉在直播与画作上——她这一格的视觉叙事围绕乐器与乐谱展开。具体发色、瞳色与衣装细节官方页只有图像，未核实。

## 六、可复用要素

1. **F08 音乐与作品化** — **与「传统 hololive 偶像路线」的对照就在这里**：她所在的 ReGLOSS 在官方发布口径里被称为「音楽アーティストVTuberグループ」，而不是偶像组合；价值锚点从「偶像祭典里的成员位」换成「作品与 Live 的曲目完成度」——1st Album → 2nd Album「Snapshot」→ 有明アリーナ 1st Live → AR Live，四级都是可单独检视的产品。可迁移动作：先决定自己被放进哪一种产品清单，再倒推内容形态；「不做偶像」不是态度，而是一份可被官方措辞证实的定位。
2. **F11 平台算法红利的捕捉** — AR Live 采用「YouTube 免费 + SPWN／ZAIKO 付费」双轨，把免费流量与付费转化分开承接；而 AR Live 的互动设计（观众评论浮现在成员胸针周围、应援浮现在整个舞台空间）本质上是把弹幕变成演出内容，让「在哪个平台看」不再只是分发问题。可迁移动作：为同一场演出准备两种平台契约，一种负责触达、一种负责收入。
3. **F06 组合网络效应** — 她的外部露出大多不是单打独斗：双人曲与 一条莉々華，餐饮联名与 大空スバル，游戏联动与同组 轟はじめ，Live 以 ReGLOSS 四人编制推进。可迁移动作：把个人作品设计成需要另一个人在场的形态（对唱、双人企划、二人直播），让对方的观众池替你完成一次分发。
4. **F01 一秒可辨识的视觉符号** — 🎹✨ 与「音楽家の卵」是可直接画成图标的一组符号，而开场语「ドレミファソラシド～！」把同一个符号搬进了听觉：看到琴键、听到音阶就知道是她。可迁移动作：让视觉符号与登场声音指向同一件东西，识别就同时发生在眼睛和耳朵上。
5. **不可迁移的部分** — hololive DEV_IS 的设立时机与 ReGLOSS 的「音楽アーティスト」定位由カバー在 2023-09 一次性决定，个人势无法获得这份**组织级定位说明书**；有明アリーナ、AR Live 的实写舞台 + Unreal Engine 技术栈、SPWN／ZAIKO 的售票通道都是事务所资产。ReGLOSS 的组成还发生过变化——同期 火威青 已毕业，说明这条路线本身也在承受成员流动。同期 [[一条莉々華]]、[[水宮枢]]、[[綺々羅々ヴィヴィ]] 共享同一份 DEV_IS 定位，但各自的产出曲线差异很大。

## 七、人物形象分析

- **人物形象**：**参考图是 hololive 官方艺人页的全身立绘**（1000×1556、竖构图）。金发长到腰下、发梢渐成蜜桃橘色，左侧一缕扎起并用红蝴蝶结固定，另一侧翘起呆毛；发间一枚**音符造型发夹**。瞳色为粉红，脸圆。头身比按目测约 6–6.5 头身（**目测，未核实**；官方档案身高 153cm），比例明显偏短、偏可爱。姿态是一手抬到肩前、另一手向侧上方伸出，一条腿屈起交叉，重心单侧——一个**指挥／起拍的手势**，而不是偶像的定点姿势。拟人化母题是**键盘乐器**：音符发夹、外套下摆的钢琴键图案、胸前的十字键纹，都是同一母题的重复。
- **性格分析**：官方写「クレッシェンドな日々を過ごす音楽家の卵」「喜怒哀楽が表に出やすく…苦手なことにはつい眉をひそめてしまう幼さがまだ残っている。けれど、美味しいご褒美があれば話は別」——**情绪外露、有幼态、好用甜食哄**。图与文一致：她的表情是标准的开朗笑脸，手势是主动向观众发出的邀请，整张图读出来是「想把事情做给你看」，而不是「想被你仰望」。这份「幼さ」正是她「音楽家の卵」这一身份的时间感来源——**卵**这个字本身就承认了尚未完成。
- **服装分析**：结构是「学院风外套 + 钢琴键礼服」，三层：白色长外套（袖口与下摆滚红白边）→ 米色格纹连衣裙（双排扣、胸前十字键纹）→ 内层白色衬衫领 + 红色缎带蝴蝶结。**外套下摆左右两侧各印一段钢琴键**，是全套设计里信息量最大的一处：它把「乐器」直接变成服装的结构线。下身是深棕过膝袜（袜口有红白条纹与腿环）配白色玛丽珍鞋（鞋头红蝴蝶结）。配饰清单：音符发夹、红蝴蝶结、格纹裙、钢琴键下摆、腿环、玛丽珍鞋。功能性上，这套衣服的**对称双排扣与琴键下摆是「正面静止也好看」的设计**——很适合被截成半身头像与卡片；抬高的一只手则给了画面一条斜向动线，让静态立绘不至于呆板。不可见的边界要说清：立绘只给出正面站姿，**外套背面、裙摆背面与她在实际 Live 中的 3D 造型差异看不到**，本卡不从这张图推断。
- **表情分析**：立绘表情是**张嘴笑 + 双眼弯起 + 眉毛抬高**，粉红瞳孔带明显高光，脸颊有淡红晕。整体读出来是「开心、期待、有点急切地想说话」。官方把「喜怒哀楽が表に出やすい」写进设定，意味着她的表情谱**幅度大**：笑会大笑、不满会直接皱眉（官方原话是「苦手なことにはつい眉をひそめてしまう」）；**除本张立绘外，其他表情的实际画面本卡未核实**。
- **常用语言分析**：开场固定台词「ドレミファソラシド～！hololive ReGLOSSの音楽家の卵！音乃瀬～奏で～～～す！」——**登场第一句是音阶而不是问候语**，把「先出声、再说话」的顺序写进了登场动作，也让「拉长音的『奏で～～～す』」成为一个可被弹幕接走的复读单元。粉丝名「音の勢」，配信 tag「#生音乃瀬」，艺术 tag「`#Artnose`」，推しマーク 🎹✨——她的语言体系整体围绕「音」这一个字：名字、粉丝名、tag、招呼语全都指向同一个语义场。
- **人物情绪分析**：情绪光谱是**高振幅、外露型**，官方直接写明「表に出やすい」，且给了一个明确的开关——「美味しいご褒美があれば話は別」。这意味着她的情绪可以靠**小道具**被调度：给吃的就能把负面情绪转成正面的可看内容。对内容的作用是：**日常杂谈不需要复杂企划，靠她自己的反应起伏就能成立**；代价是情绪同时会成为最容易被切片的素材，高低起伏都会被放大。

**冲突消解记录**：自动丢掉了 **2** 个打架的负向词——赛璐璐风格层本来禁止的 `soft gradient shading` 让位于洛可可光照层要求 `shading`、`muddy colour` 让位于 `colour`。原因：跨流派混搭时负向词会互相打架，**不丢就会把对方想要的元素也排除掉**（赛璐璐要「平涂、无渐变」，洛可可光照要「柔和漫射、几乎无影」，若保留原负向词，洛可可那层的光就被自己的负向词抵消掉了）。这一组混搭的取法也说明分层的意义：**风格层用赛璐璐拿到硬边平涂与清晰线稿，光照层用洛可可拿到柔和漫射光**，两者的负向词之所以打架，是因为它们本来服务于不同的画面观感。

**可迁移 / 不可迁移**：可迁移的是**「把乐器写进服装结构」这一招**——不必给角色一把乐器，而是让服装本身的图案承担乐器符号（琴键下摆、谱线袖口、音符发夹），以及「暖色邻近 + 深色收边 + 小面积高频点缀」这套适合卡片化的配色策略；「登场第一句不问候而是发出一个音符」的听觉设计同样可以换主体复用。不可迁移的是绑定：金发渐变蜜桃橘 + 粉红瞳的组合、钢琴键下摆 + 双排扣学院外套这个具体剪影、153cm 的矮小比例，以及「音楽家の卵」这一由カバー 官方口径支持的定位都不是能顺手换掉的——**换掉定位而保留造型，等于把她的作品线剥掉只留下可爱的壳**。
