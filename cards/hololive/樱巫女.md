## 六、可复用要素

1. **F04 反差结构** — 「自称精英」与「粉丝公认翻车」的落差是她全部内容的引擎，官方甚至把「ポンコツ」写进档案。可迁移动作：把自称与实际的落差写成官方设定的一部分，让观众能预判并期待翻车。
2. **F02 声音记忆点** — 语尾「○○にぇ」与招呼「にゃっはろ～！」是被官方收录的固定符号。可迁移动作：给角色设计语尾级别的发音标记，它的可检索性高于普通口头禅。
3. **F07 二创友好的分发契约** — 她为配信、绘、MMD 分别给出 tag，等于给三类创作者各发一份明确的「分发契约」。可迁移动作：按创作媒材分列 tag，而不是只给一个总 tag。
4. **F08 音乐与作品化** — 从原创曲到 2nd 专辑＋K アリーナ单人 Live，音乐成为与直播平行的资产线。可迁移动作：让专辑与 Live 共用同一官方 tag，把两者绑成一个可传播的事件。
5. **F06 组合网络效应** — 她同时处在 0 期生、hololive 全员 Live 与「エリート陰陽師みこ」这类以她为主角的 holo Indie 游戏里，箱内网络被反复复用。可迁移动作：主动把自己的符号授权给同生态的第三方（游戏、同人品牌），换取曝光面。
6. **不可迁移的部分** — 参考书、绘本这类出版机会来自 Gakken、集英社等厂商**已经把她认定为儿童/学生群体的安全符号**，这个认定依赖多年无重大负面与 hololive 的品牌背书；个人势或新人即便做出同样人设，也拿不到同级别的出版社采购，这属于时机与信用的复利，不可迁移。她在 0 期生里的先行位置同样不可复制——同期的 [[常夜空]] 拿的是同一份最早期红利。

## 七、人物形象分析

- **构图与取景边界**：参考图是**全身立绘**（1000×1556，竖构图，人物单脚抬起、呈跳跃态），可以读到从发饰到脚下木屐的完整层次；但姿势本身是跳跃造型，**身体比例被动态夸张，不能由这张图反推真实身高（官方档案 152cm）**。
- **人物形象**：粉色短发（侧马尾＋金／红发饰＋樱花瓣装饰）＋**绿色眼睛**、单眼眨、露齿笑；白红配色的巫女装改良成偶像式短裙，手里举着**神乐铃（祓串／御币）**，一只脚向后踢起。整体剪影是「巫女 × 偶像」——上半身保留神社装束的领口与振袖轮廓，下半身换成能大幅活动的蓬松短裙。母题是**电脳桜神社的巫女**，视觉上把「神社」做成可跳跃的舞台，而不是静态的宗教场所。
- **性格分析**：官方档案写目标是成为「唯一無二のトップエリート巫女アイドル」，同时补了一句「『エリート』と自称しているが、ファンの間では『ポンコツ』という噂も…」。立绘把这句话的两端同时画了出来：**「エリート」写在姿势上**（举神器、单眼眨、抬腿，完全是自信的舞台亮相），**「ポンコツ」留给内容去兑现**。这是她人设的核心机制——外形负责承诺，内容负责违约，落差本身就是节目。
- **服装分析**：白色振袖（红色菊纹与花瓣纹、红色袖口、金色滚边、前襟红绳结）＋红色围裙式前挡（带白色樱纹与蝴蝶结）＋**大面积金色腰封**（上有白色樱瓣图案与一枚粉色樱花结）＋粉色印花百褶短裙（樱花散布）＋金色袖丸（两侧垂挂的金色球状饰）＋白色过膝袜（粉色镶边与腿环）＋红白绳结发饰＋粉／红色木屐。道具为神乐铃（金色铃串＋红白缎带）。设计思路是**「和风符号保留在领口与袖型，把活动性交给裙摆」**——振袖的宽袖与腰封后的蝴蝶结在 Live2D 里是天然的飘动部件，短裙则让抬腿、跳跃这类偶像动作成立。
- **表情分析**：基准是**单眼 wink ＋ 张嘴露齿笑**（可见一颗小虎牙），眉眼上扬，气息是「非常有把握」。这套表情的关键在**自信的绝对量**——因为自信越满，后续翻车时的落差越大。常见表情谱：得意笑（招牌）／眯眼撒娇／夸张的慌张与瘪嘴（「ポンコツ」状态的兑现）。**本立绘只给出了自信端的差分**，慌张端的差分属于动画／配信表现，不在这一张图里。
- **常用语言分析**：官方 meme 列表收录的招呼「にゃっはろ～！」与收尾「おつみこ～！」；语尾「○○にぇ」（「ねぇ」的变体）；信念句「諦めない心にぇ」；自嘲梗「み俺誇／み俺恥」。可复读性很高——「にぇ」是**语尾级**的发音标记，出现在几乎每一句话里，检索性高于普通口头禅；「にゃっはろ～！」与「おつみこ～！」则把开场与收尾各占了一个固定位置，等于在每场直播的头尾各钉一个免费的记忆点。
- **人物情绪分析**：情绪光谱是**高能量、易兴奋、也易慌张**——「精英」与「ポンコツ」是同一条光谱的两端，不是两个角色。触发点是「努力之后的翻车瞬间」，而她的情绪设计恰恰把**翻车点做成情绪的最高音**：观众不是来看她成功的，是来看她如何在不顺里继续喊「諦めない心にぇ」。这套情绪直接服务于内容：它让「失败」变成可长期复用的节目单元，而不是需要回避的事故。立绘里那个把脚踢起来、举着神乐铃的姿态，就是这条光谱的起点——从最自信的位置开始往下掉。
- **配色分析**：
 - 客观测量（原图）：主色 `#FCFAFA` 85% ／ `#E79DA0` 4% ／ `#DA5869` 4% ／ `#CE2B5A` 3% ／ `#AB2855` 3% ／ `#E3A564` 2%；明度 均值 228.0、高明调；对比 RMS 49.1／Michelson 0.496，中等对比；饱和度 0.126；色温 暖（+23）；主色相 红 349°；和谐 中等多色。
 - **测量伪影（必须点明）**：这张登记图是**透明底**（文件虽为 `.png`，实际按透明底处理）。工具按 RGB 读图会把**透明区记成纯白**，所以 `#FCFAFA` 的 **85% 里，绝大部分是透明背景**；「高光溢出 64.79%」同样是这个伪影的一部分。
 - **背景/透明底占比陷阱**：这里有一个**容易看错的双重陷阱**——她的服装本身也是大面积白色（振袖、过膝袜），所以**不能反过来把 85% 全部当成背景就完事**：正确读法是「85% ＝ 透明底 ＋ 白色服装，两者按 RGB 无法分离」，因此**白色只能确认「占比很大」，无法给出服装白的可靠比例**。真正可以确定属于角色的彩度来自后几位：粉 `#E79DA0`、红 `#DA5869` 与 `#CE2B5A`、深红 `#AB2855`、金 `#E3A564`。
 - 角色主色：白（振袖／袜，与透明底不可分离）、粉 `#E79DA0` 与红 `#DA5869`／`#CE2B5A`（裙、袖口、前挡、发）、深红 `#AB2855`（阴影侧与绳结）、金 `#E3A564`（腰封、滚边、袖丸、铃）。
 - 配色策略：**白 ＋ 粉红 ＋ 金**的邻近色骨架，明度整体很高、饱和度中等（0.126），色温暖，主色相落在 349° 的红段。有效性在于「白底上只用红与金做重音」——在缩略图里白色让轮廓干净，红与金负责在 1 秒内被认出；风险是整体明度太高、对比只有中等（RMS 49.1），小尺寸下容易发飘，所以正片里她大量依赖**高饱和的红**来压住画面。这也解释了她为什么要在白色巫女装之外加大块金色：**金是补对比的那一手**。

**冲突消解记录**：artvault 自动丢掉了 **2** 个打架的负向词——风格层原本禁止 `soft gradient shading` 与 `muddy colour`，两个都让位于洛可可光照层正向要求里的 `soft` 与 `colour`。**原因是**洛可可这一层要的正是「柔光、接近无影」，而赛璐璐风格层的负向里习惯性排除「软渐变」；洛可可的配色正向词又带 `colour`，与赛璐璐禁的 `muddy colour` 撞在同一 token 上。不丢掉这两个，就会把她这套「高明调、无压迫感」的光照要求一并排除，两层里负责光的那一层会直接失效。**丢掉的是它们。**

**可迁移 / 不可迁移**：
- **可迁移的设计动作**：①**「精英自称 × 翻车兑现」的双端设计**——把承诺写在造型与表情里（举神器、眨眼、抬腿），把违约留给内容去完成，落差不需要写脚本；②**和风符号留在领口与袖型，活动性交给裙摆**——要同时保住文化母题辨识度和偶像动作幅度时的分层解法；③**高明调画面必须补一个高饱和重音色**（这里是金与红），否则缩略图会发飘；④把开场与收尾各钉一个固定短句（「にゃっはろ～！」／「おつみこ～！」），头尾各占一个免费记忆位；⑤**语尾级的发音标记**（「○○にぇ」）优先于普通口头禅，因为它每句话都会自动复现一次。
- **不可迁移的部分**：粉发＋绿眼这一组具体外观；「电脳桜神社的巫女」这个设定与「ポンコツ」这个反差标签在 hololive 0 期生里已被占用；参考书、绘本、47 都道府县地方版这类出版采购依赖厂商「把她认定为儿童与学生群体的安全符号」的多年认定与 hololive 品牌背书。可迁移的是**这五个设计动作**，不是这套白粉金。
