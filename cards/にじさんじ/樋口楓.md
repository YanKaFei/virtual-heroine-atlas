# 樋口枫 / 樋口楓

> **一句话定位**：にじさんじ 一期生里把「长期杂谈 + 音乐作品」熬成复利的那一个——用八年零中断的在场把自己做成箱内可被反复调用的连接点，2026-02 才拿到百万订阅。

> 出道：2018-02（公开报道引述 ANYCOLOR 官方发表「2018年2月にデビュー」）｜ 主平台：YouTube

## 一、身份

- **角色设定**：ANYCOLOR 官方发表的简介为「VR 関西に住む高校 2 年生。長身でスタイルも抜群。幼い頃からトランペットが好きで、現在は吹奏楽部に所属している。オシャレをすること、猫と暮らすことが生きがい。好きなものについてもっと知ってほしくて、ライバー活動を始めた」。这一设定里「想把自己喜欢的东西讲给别人听」被直接写成了活动动机，与她的内容形态一致。
- **中之人公开信息**：本库不涉及。
- **商业位置**：にじさんじ 一期生（元 1 期生）。她是 にじさんじ 内资历最长的成员之一，也是官方音乐单元「七次元生徒会！」的成员——该单元成员为 叶、樋口楓、三枝明那、仙河緑、レオス・ヴィンセント、周央サンゴ。2026-02-16 她的频道突破 100 万订阅，同日 リゼ・ヘルエスタ 也达成同一里程碑。

## 三、视觉与声音设计

- **视觉**：官方设定给出两个可画的识别点——「長身」与「吹奏楽部」的校园制服形象；演唱会现场则用另一组视觉锚点建立连续性：她的开场影片里是拉着橙色行李箱走在机场的制服造型，登台时说「ただいまー東京」并带着同一只行李箱。**道具（行李箱）被当成跨城市巡演的可追踪符号**。发色与瞳色的具体色值官方资料未以文本给出，未核实。
- **风格坐标**：校园吹奏乐部题材的造型，舞台侧则切换到裤装艺人气场（公开资料记她在「恋すな」一曲时换成パンツルック的アーティスト衣装、配合舞厅镜球）；造型在两套语言之间切换是她的舞台设计特征。具体美术流派归属未核实。
- **声音**：官方将她的核心能力写作「力強い歌唱力」；配信侧以杂谈与游戏为主，声音资产横跨「关西腔的轻松杂谈」与「厚重的摇滚式演唱」两端。演唱会里她会亲自录制开场前的影ナレ（后台广播），把声音本身做成现场体验的一部分。
- **动捕/模型路线**：にじさんじ 的 Live2D → 3D 路线；她的现场为真实会场（J:COM ホール八王子，最大容纳 2021 人）配横长主屏与 3 面副屏的 VTuber 演唱会形态，并使用生乐队伴奏。

## 四、内容结构

- **主内容型**：杂谈与游戏配信为日常基底（官方口径为「YouTube では主に雑談やゲームなどの配信活動や Shorts を中心とした動画投稿」），音乐为第二支柱（出道单曲、专辑、迷你专辑、单独巡演），组合企划为第三支柱（七次元生徒会！、にじさんじフェス 等）。

- **剪辑与切片策略**：官方口径提到 she 以 Shorts 为中心做视频投稿，说明短视频已是她的常规分发口径；演唱会侧则用连续叙事把单曲串成可追的现场（如「Feel it Now」在屏幕上做成恋爱游戏的 5 选项分支，最后必定 game over，她本人在台上瘫倒）。组合侧用统一设定（七次元生徒会！）把六个人的素材串成可追更的产品线。
- **互动机制**：官方商店与粉丝俱乐部是主要互动入口；百万订阅纪念采用受注生产（2026-06-09 至 07-08）而非即时上架，把「纪念」做成一次带期限的参与行为。组合侧设有 2027-01-23 的剧场版 Live 先行抽选序列号，把专辑购买与线下活动绑定。

## 六、可复用要素

1. **F09 长期在场的复利** — 八年、2152 支投稿〔实测 2026-09-15〕、百万订阅晚到，但每次产出都挂在同一条主线上（配信 → 音乐作品 → 巡演 → 组合专辑）。可迁移动作：把「不换赛道」当成明确策略来执行，允许里程碑晚到；跨年度的产品序列（单曲 → 专辑 → 巡演）比单次爆款更能维持商业价值的连续性。
2. **F06 组合网络效应** — 她同时挂在事务所级单元（七次元生徒会！）、事务所全员活动（にじさんじフェス）、以及他人主办的活动上（作为嘉宾出演 叶 的 2nd Live、为后辈 瀬戸美夜子 作词曲目做现场致敬）。可迁移动作：主动进入多个组合的成员名单，让同社成员的观众池反复交叉；组合专辑还自带跨成员的线下活动（2027-01-23 剧场版 Live 先行抽选），把音乐产品直接换成到场行为。
3. **F08 音乐与作品化** — 官方口径把「力強い歌唱力」列为她的核心能力，而她的音乐产出走的是稳定的产品节奏：出道单曲 → 2nd 专辑 → 2nd 迷你专辑；演唱会则把音乐做成可被记住的现场叙事（恋爱游戏分支、纪念后辈的演出细节）。可迁移动作：让音乐产出有可预期的发行节拍，并在现场给每首歌配一个具体可描述的桥段。
4. **F07 二创友好的分发契约** — 官方把她纳入以 Shorts 为中心的视频投稿口径，组合侧又给每位成员分配了固定的门店立牌位置（她的在アニメイト渋谷店），等于把「去哪里能看到她、能拍什么」写成了公开信息。可迁移动作：把粉丝的线下行为路径（打卡点、拍照位、特典）设计成官方信息的一部分。
5. **不可迁移的部分** — 2018 年 にじさんじ 一期生的出道窗口与「元 1 期生」这一资历身份不可复制；她的组合网络依赖 ANYCOLOR 同期成员之间八年的合作关系，个人势无法采购；「八年才过百万」这条曲线在今天的算法环境下也不再是默认路径——2025-2026 年的头部增长更多来自 Shorts 与单点爆款。同期 [[月之美兔]] 走的是同一条一期生长期主义路线，但内容形态（混沌喜剧 vs 音乐与杂谈）完全不同，说明这条路线没有统一模板。

**冲突消解记录**：自动丢掉了 **2** 个打架的负向词——风格层的 `soft gradient shading` 让位于另一层要求的 `shading`（装饰艺术的光照层要的是硬几何光斑与放射状光，柔和渐变阴影与它正面冲突），风格层的 `muddy colour` 让位于另一层要求的 `colour`（赛璐璐平涂必须讨论 colour）。值得注意的是这一组**没有**丢 art-deco 自带的负向词（`organic whiplash curves`、`art nouveau vines` 等全部保留），因为装饰艺术与新艺术运动的否定项恰好不与被借用的光照层打架——**原因**是跨流派混搭时只有真正互相打架的负向词才会被丢掉，丢掉它们是为了不把对方想要的元素也一起排除掉；未冲突的词一律保留。两条均可用 `--keep-conflicts` 复核。
**可迁移 / 不可迁移**：可迁移的是「纯色底 + 白色剪影描边 + 单色相人物」的头像语法，以及「用明度对比（而非饱和度）保证小尺寸可辨识」的做法——这两点任何角色都能复刻。不可迁移的是灰银高马尾 + 紫瞳 + 紫格纹领带的组合（它是这个角色的识别符号），以及官方设定里的「長身」「吹奏楽部」「関西腔」「八年长期在场」这些绑死在本人履历上的属性。
