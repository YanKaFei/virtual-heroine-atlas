**132명의 여성 버추얼 캐릭터가 왜 뜨고, 어떻게 디자인되었는지를 기록한 연구 아틀라스.**

Obsidian으로 열 수 있고, CLI로 조회하며, DeepSeek Harness에서检索할 수 있습니다.

[中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어** · [Français](README.fr.md)

## 무엇을 담고 있나

- 132명의 버추얼 스트리머/버추얼 캐릭터
- 한 사람당 한 장의 카드
- 왜 주목받는가: 콘텐츠·운영 분석
- 어떻게 디자인되었는가: 색, 의상 구조, 표정, 언어 습관, 감정 포지션
- 이미지 모델에 넣을 수 있는 레이어형 프롬프트

## 사용

```bash
python3 query.py --help
```

Obsidian에서 카드와 이미지를 열고, CLI/DSH에서 검색합니다.
