# AI 接口：怎么用这个库生成一个新人设

> 这个库不是给人「读」的，是给 AI **调取**的。
> 本文件是接入说明书；机器可读索引是根目录的 本库的实测数据（schema `vault.vtuber/v1`）。

---

## 一、为什么需要一层索引

132 张卡全读进上下文约 **1MB**，装不下；而且卡片里混着大量考据、来源、未核实标注——
那些对「人」有用，对「抽取设计要素」是噪音。

所以索引只抽**结构化的那一层**，细节用 `card` 字段回原卡查。
**索引是目录，不是替代品**——不要用它代替读卡。

## 三、调取接口（命令行）

bash
cd 虚拟女主播库

# 1) 找同类参考：用「低音反差」起来的人
python3 --factor F04 --fields id,one_liner --format md

# 同样的筛选在 Obsidian 里：打开，切到「F04 反差结构」视图
# （那个文件由 从 爆火要素模型.md 生成，不要手改）

# 2) 限定平台 / 语言 / 阵营 / 状态
python3 --language 韩语 # 按语言筛（日语/英语/中文/韩语/印尼语）
python3 --platform B站-个人势 # 按出道平台目录筛
python3 --affiliation 独立 # 按阵营筛
python3 --status 毕业 # 只看已毕业的（历史样本）
python3 --has-image --has-prompt # 只要素材齐全的

# 3) 取一个人的完整设计层（身份 + 形象分析 + 提示词）
python3 --card 宝钟玛琳

# 4) 要完整原文（含七段考据）
python3 --card 宝钟玛琳 --full

# 5) 全文检索（找某种设计动作，例如谁在用 ASMR）
python3 --grep "ASMR"

# 6) 随机抽样做「设计动作采集」
python3 --random 6 --fields id,factors

## 四、生成新人设的正确流程（重要）

**不要**照抄某一个人的提示词。正确姿势是**拆解 → 借用设计动作 → 重组**：

① 定意图 新人设想切哪个语言位/平台？（F12）走音乐还是直播？（F08/F09）
② 筛参考 query.py --factor F12 --language 韩语 → 拿同类样本
③ 读设计层 query.py --card <样本id> → 看「八、人物形象分析」
④ 抄动作 从第七段里挑**可迁移的设计动作**（不是挑颜色）
⑤ 搭骨架 <样本>的「九、人设生成提示词」的**分层结构**（风格层/光照层/构图层）
⑥ 换主体 把主体描述换成新角色；风格层可跨样本重混
⑦ 查冲突 artvault compose 会自动丢掉打架的负向词——**必须说明丢了什么**
⑧ 自检 用 打分，重点看 0 分项

### 「可迁移 / 不可迁移」是这一步的关键

每张卡的第八段末尾都有这一行。生成新人设时**只搬可迁移的**：

- ✅ 可迁移：视觉母题的构造方式、表情谱的分布、配色策略（明度对比/饱和度层级）、
 提示词的分层结构、口癖的「可复读性」设计
- ❌ 不可迁移：绑死这个人的符号（鲨鱼的鳍、狐耳）、时机红利、企业资源、
 已有的粉丝存量、已注册的 IP

## 五、几条纪律（否则生成结果会烂）

1. **数字必须回索引拿**，不要在生成时凭印象写「约 300 万」——索引里的值有实测日期。
2. **`null` 是「未核实」，不是 0**。别把 平台公开数据 当成「她没有 B 站粉丝」。
3. **图是参考不是素材**：`99-attachments/立绘/` 下的图版权属官方与创作者，
 **仅供个人参考**，不要拿去二次分发或训练（详见 本库的实测数据）。
4. **别把「幸存者偏差」当配方**：模型文件末尾写明了——本库分析的是活下来的头部，
 同等质量但没火的人远多于她们。
5. **跨平台数字不可比**：B 站粉丝与 YouTube 订阅不是一套口径。

## 六、这个接口**不**提供什么

- ❌ 不提供中之人身份、争议与八卦（本库的 non-goal）。
- ❌ 不提供可商用的美术素材。
- ❌ 不提供「保证爆火」的配方——只有拆解与自检。
- ❌ 素材覆盖不均：hololive 有全身立绘，中文圈只有头像，7 位没有图。
 做跨样本视觉对比时必须留意这一点。
