# 主播卡模板

> 每张卡固定八段，段标题**一字不改**（验收按标题切段）。
> 数字纪律：凡精确数字，紧跟测量标记 `〔实测 YYYY-MM-DD〕`；取不到的写「未核实」，**不许填记忆值**。

---

## frontmatter

```yaml
---
类型: "虚拟主播"
平台: "hololive"        # 展示名，与所在目录对应
语言: "日语"            # 日语 / 英语 / 中文 / 韩语 / 印尼语；图谱按它分色
阵营: "hololive"        # 必须与正文「阵营：」完全一致
状态: "活动中"          # 活动中 / 毕业 / 停活 / 休止
出道: "2019-08"        # 查不到就显式写 "未核实"，不要省略
YouTube订阅: "442.9 万" # 没有该平台数据就整行省略
B站粉丝: ""
Twitch关注: ""
一句话: "把 X 做成 Y 的那一个。"
要素: [F01, F04]        # 从第六段的 `**F0x …**` 编号抽，按编号升序
tags:
  - 语言/ja
---
```

## 正文骨架

```markdown
# <中文名> / <原名>

> **一句话定位**：<她在生态里占的那一格，一句话>
> 平台：<展示名> ｜ 语言：<…> ｜ 阵营：<…> ｜ 状态：<…>
> 出道：<YYYY-MM 或「未核实」> ｜ 主平台：<YouTube / Bilibili / Twitch>

## 一、身份

- **角色设定**：<官方人设、自称、种族/职业设定>
- **中之人公开信息**：本库不涉及。
- **商业位置**：<所属、出道批次、同期、在团体里的分工>

## 二、实测数据

- YouTube 订阅数：<数值>〔实测 YYYY-MM-DD〕
- 总播放 / 投稿数：<数值>〔实测 YYYY-MM-DD〕
- Bilibili 粉丝数：<数值>〔实测 YYYY-MM-DD〕（若无则写「未核实」）
- 历史峰值/里程碑：<如百万订阅时间；无来源则写「未核实」>

## 三、视觉与声音设计

- **视觉**：<发色/瞳色/服装/标志性配饰；判别特征>
- **风格坐标**：<继承的视觉语言；说不出就写「未核实」>
- **声音**：<音色、语速、口癖、标志性台词>
- **动捕/模型路线**：<Live2D / 3D / 全身动捕 / AI 生成>

## 四、内容结构

- **主内容型**：<歌 / 游戏 / 杂谈 / ASMR / 短剧 / 赛事>
- **直播节奏**：<时长、频次、固定栏目>
- **剪辑与切片策略**：<切片号、Shorts/TikTok 占比、二创激励>
- **互动机制**：<SC/舰长、会员名、弹幕梗、粉丝名>

## 五、爆火节点

| 时间 | 事件 | 结果 |
|---|---|---|
| YYYY-MM | <具体作品/事件> | <可观察结果，带数字> |

- **增长曲线形态**：<一次性爆发 / 阶梯 / 长尾复利>

## 六、可复用要素

> ⚠️ 每条必须写成 `**F0x 要素名**` 的形式（编号 F01–F12）。
> 索引里的 `要素` 属性就是从这里抽的——写成别的格式，
> 按要素筛人时这张卡不会出现。

1. **<要素名>** — <她做对了什么，可迁移的动作是什么>
2. **<要素名>** — …
3. **不可迁移的部分** — <时机红利/平台红利/不可复制的资源，明确标出>

## 七、人物形象分析

<见 templates/look-analysis.md>

## 八、人设生成提示词

<见 templates/look-analysis.md>
```

## 反面清单（写卡时最容易犯）

| 禁止 | 正确做法 |
|---|---|
| 「订阅约 300 万」 | 「订阅 3,167,000〔实测 YYYY-MM-DD〕」 |
| 「她是第一个 VTuber」（无来源） | 「业界公认的早期开拓者之一，具体首播日期未核实」 |
| 把中之人身份写进来 | 只写角色与商业事实 |
| 「因为可爱所以火」 | 「可爱是结果不是原因；原因是她把 X 做成了可重复的内容形态」 |
| 只写成功不写边界 | 必须写「不可迁移的部分」 |
